# Subto

A lightweight subdomain takeover detection tool.

## Features

- CNAME-based subdomain takeover detection
- CNAME fingerprint matching
- HTTP response fingerprint checking
- Body and response header fingerprint support
- Configurable threads and request timeout
- Single target and target list scanning
- Provider confidence levels
- YAML-based fingerprints

> Note: Subto currently only supports CNAME-based subdomain takeover detection.

## Update

Subto may be updated over time with new features, improvements, and fingerprint updates.
